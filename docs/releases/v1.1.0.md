# Pseudoharness 1.1.0

This release expands the desktop app with a local saved-skills library, explicit skill selection and provenance, scoped AgentMem MCP tools and audit records, improved pass and receipt verification, and native browser navigation and window controls. It also includes dependency security fixes for the compressed JSON parser and URI handling.

## Downloads

- Windows x64 installer (NSIS)
- macOS x64 ZIP
- macOS arm64 ZIP

The desktop packages are currently unsigned and are not notarized. macOS may ask you to confirm before opening the app.
