# Pseudoharness 1.1.2

The Windows installer now requests administrator permission when opened and installs the application for all users. Upgrading from the prior per-user installer migrates the application files while preserving the signed-in user's app data and saved skills. The installed app continues to run as the signed-in user.

## Downloads

- Windows x64 installer (NSIS)
- macOS x64 ZIP
- macOS arm64 ZIP

The desktop packages remain unsigned, and the macOS packages are not notarized.
