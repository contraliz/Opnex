# Opnex 1.1.3

The conversation log is now a Markdown/CLI-style document. Each pass opens with the router's decision and its plain-text reason, then the orchestrator turn, then collapsible Workers, Tool calls, Receipt, and Final output sections separated by hairline rules and marked with `[−]`/`[+]` instead of cards. Status and routing-decision words use a muted six-color text palette; tool results stay green and red.

Token usage closes the final report. Collapsed, the block shows the pass total; expanded, it breaks tokens down by model and role with input, cached, output, reasoning, and total columns. Rows appear as soon as a role reports usage, and roster, assignment, and tool-call details are flattened into the same key/value and mono type.

Also in this release: the composer shows the selected model with a single circular send control, and the run controls become Stop and Steer while work is active. Sessions can be pinned, archived, and reordered from the session list. The model chooser groups Codex and DeepSeek Harness models with a reasoning side panel shared with Settings, and saved skills import SKILL.md front matter correctly and open as rendered Markdown. Forge tickets carry an explicit access mode and resolve the Opnex knowledge skill from the saved library.
