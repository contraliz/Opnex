# Pseudoharness 1.1.1 — corrected desktop packages

The existing v1.1.1 release page now serves rebuilt desktop packages from the corrective source commit recorded below. The published Git tag and its history remain unchanged.

The Windows installer requests administrator permission and installs for all users. It migrates the prior per-user installation while preserving the signed-in user's app data and saved skills. The installed app continues to run as the signed-in user.

Packaged saved-skills and AgentMem MCP helpers now launch with an official bundled Node.js 24.22.1 runtime for the matching platform and architecture. This works with Electron's RunAsNode fuse disabled and does not depend on a system Node installation. The helper runtime includes the Node.js license.

The release includes the saved-skills library, explicit skill selection and provenance, scoped AgentMem MCP tools and audit records, improved pass and receipt verification, native browser navigation and window controls, and dependency security fixes. The macOS test fixtures run without relying on a developer's local Codex configuration.
