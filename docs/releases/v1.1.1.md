# Pseudoharness 1.1.1

This is the first complete packaged release of the 1.1 series. It includes the saved-skills library, explicit skill selection and provenance, scoped AgentMem MCP tools and audit records, improved pass and receipt verification, native browser navigation and window controls, and dependency security fixes.

The macOS test fixtures now run without relying on a developer's local Codex configuration, and filesystem-path assertions account for macOS canonical paths.

## Downloads

- Windows x64 installer (NSIS)
- macOS x64 ZIP
- macOS arm64 ZIP

The desktop packages are unsigned and the macOS packages are not notarized. macOS may ask you to confirm before opening the app.
